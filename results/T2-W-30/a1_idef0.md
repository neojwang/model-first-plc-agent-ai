## A0 context model — Control timed tank filling

**Scope:** Control the digital tank’s fill valve using a timed filling step, with stop and high-high-level interruption. Keep the discharge valve closed.

Signal identifiers below follow the required vocabulary. Physical PLC tags are mapped to these identifiers separately.

### ICOM model

| Node | Function | Inputs | Controls | Outputs | Mechanisms |
|---|---|---|---|---|---|
| **A0** | **Control timed tank filling** | Operator button signals; level-switch signals | `TimerDuration`; initial-step requirement; stop priority; high-high cutoff requirement; discharge prohibition; I/O address mapping | Fill-valve command (`fill_valve`); discharge-valve command (`discharge_valve`) | OpenPLC Runtime; PLC scan execution; Modbus TCP connection; Factory I/O tank scene; capacitive level switches; valve actuators |
| **A1** | **Interpret operator and level signals** | Operator button signals; level-switch signals | I/O address mapping; rising-edge definition of `start`; active-high signal definitions | Start event (`start`); stop status (`stop`); target-level status (`LSH`); high-high-level status (`LSHH`) | OpenPLC input image; rising-edge detector; retained button-history memory |
| **A2** | **Select the operating step** | `start`; `stop`; `LSHH`; `timer_done` | Initial-step requirement; step-transition rules; stop priority; high-high cutoff priority | Operating-step state | PLC sequence logic; operating-step memory |
| **A3** | **Measure the filling interval** | Operating-step state | `TimerDuration`; timer enable and reset rules | Timer-completion status (`timer_done`) | Non-retentive on-delay timer; PLC time base |
| **A4** | **Command the tank valves** | Operating-step state; `stop`; `LSHH`; `timer_done` | Idle-output requirement; filling-output requirement; stop priority; high-high cutoff priority; discharge prohibition; I/O address mapping | Fill-valve command (`fill_valve`); discharge-valve command (`discharge_valve`) | OpenPLC output image; Modbus TCP connection; Factory I/O valve actuators |

All arrow labels are noun phrases; labels such as `start` and `timer_done` denote the corresponding event or status.

## Child-function connections

These connections provide the internal arrows of the A0 decomposition:

| Source | Arrow | Destination |
|---|---|---|
| A0 boundary | Operator button signals; level-switch signals | A1 |
| A1 | `start`; `stop`; `LSHH` | A2 |
| A1 | `stop`; `LSHH` | A4 |
| A2 | Operating-step state | A3, A4 |
| A3 | `timer_done` | A2, A4 |
| A4 | `fill_valve`; `discharge_valve` | A0 boundary |

`LSH` is an intentionally unused monitoring output of A1. It has **no connection to the sequence or valve decisions** in this timer-based task. In a graphical IDEF0 diagram, show it as a documented tunneled output rather than as an unexplained dangling arrow.

## Behavioral controls

These rules define the controls referenced in the ICOM table; they are not PLC code.

| Control | Definition |
|---|---|
| Initial-step requirement | Initialize the operating-step state to **step 0 — idle**. |
| Step-transition rules | From step 0, accept `start` only when `stop` and `LSHH` are FALSE, then enter **step 1 — filling**. From step 1, return to step 0 when `timer_done`, `LSHH`, or `stop` is TRUE. Otherwise retain the current step. |
| Stop priority | Whenever `stop` is TRUE, select step 0 and force both outputs FALSE, regardless of other signals. |
| High-high cutoff priority | `LSHH` prevents filling and terminates an active fill. A simultaneous `start` must not override this cutoff. |
| Timer enable and reset rules | Enable the timer on entry to step 1. Assert `timer_done` when the filling interval reaches `TimerDuration`. Disable and reset the timer outside step 1. |
| Idle-output requirement | In step 0, `fill_valve` and `discharge_valve` are FALSE. |
| Filling-output requirement | In step 1, `fill_valve` is TRUE only while `stop`, `LSHH`, and `timer_done` are FALSE. |
| Discharge prohibition | `discharge_valve` is always FALSE. |

A held StartCommand does not initiate another fill after completion: `start` occurs only on a new button-press edge.

## Physical I/O mapping

| Physical tag | Address | Model identifier | Interpretation |
|---|---|---|---|
| StartCommand | `%IX100.0` | `start` | TRUE only during the scan detecting a FALSE-to-TRUE transition |
| StopCommand | `%IX100.1` | `stop` | TRUE while the stop command is active |
| LSH | `%IX100.2` | `LSH` | TRUE when liquid reaches the 2.4 m target switch; monitoring only |
| LSHH | `%IX100.3` | `LSHH` | TRUE when liquid reaches the 2.7 m overfill switch |
| FillValve | `%QX100.0` | `fill_valve` | TRUE opens the fill valve |
| DischargeValve | `%QX100.1` | `discharge_valve` | Always FALSE |

`timer_done` is an internal receptivity generated by A3, not a mapped physical input. `TimerDuration : TIME` is a control parameter, not a plant signal.
