### Scope and conventions

This model describes the **controller**, not the tank’s material flow. Boolean signals are information inputs; valve commands are information outputs. Function names are verb phrases, and arrow names are noun phrases.

`start` is the specified one-scan press event derived from `StartCommand`; `stop` corresponds to `StopCommand`. `timer_done` is an **internal arrow**, generated by the timing function rather than an external controller input.

| Node | Function | Inputs | Controls | Outputs | Mechanisms |
|---|---|---|---|---|---|
| **A0** | **Control timed tank filling** | `start`; `stop`; `LSHH` | `TimerDuration`; initial-step requirement; start acceptance rule; timer-or-overfill termination rule; stop-priority rule; discharge-inhibition requirement | `fill_valve`; `discharge_valve` | OpenPLC Runtime; controller program; Modbus TCP interface; Factory I/O tank scene and mapped I/O |
| **A1** | **Determine the operating step** | `start`; `stop`; `LSHH`; `timer_done` | Initial-step requirement; step-transition rules; stop-priority rule | Operating-step status | OpenPLC Runtime; step-state memory |
| **A2** | **Measure the filling interval** | Operating-step status | `TimerDuration`; timer activation and reset rules | `timer_done` | OpenPLC Runtime; timer instance; runtime time base |
| **A3** | **Generate valve commands** | Operating-step status; `stop` | Step-output rules; stop-priority rule; discharge-inhibition requirement | `fill_valve`; `discharge_valve` | OpenPLC Runtime; output mapping; Modbus TCP interface |

### Meaning of the controls and internal arrows

- **Initial-step requirement:** Initialize the controller in step 0, with no active outputs.
- **Step-transition rules:**
  - Accept `start` in step 0 and enter the filling step.
  - Leave the filling step and return to step 0 when `timer_done` or `LSHH` is TRUE.
  - Whenever `stop` is TRUE, select step 0 regardless of other signals.
- **Operating-step status:** The internally retained indication of step 0 or the filling step. A1 supplies it to A2 and A3.
- **Timer activation and reset rules:** Start timing upon entry into the filling step, assert `timer_done` when `TimerDuration` has elapsed, and reset the timer outside the filling step. A2 feeds `timer_done` back to A1.
- **Step-output rules:** Set `fill_valve` TRUE only in the filling step; otherwise set it FALSE.
- **Stop-priority rule:** While `stop` is TRUE, both outputs are FALSE.
- **Discharge-inhibition requirement:** Keep `discharge_valve` FALSE throughout operation.

**Unused mapped signal:** `LSH` is available at the I/O boundary but has no specified role in this task. It therefore does not appear as a consumed functional input; in particular, reaching the 2.4 m target level does **not** terminate filling.
