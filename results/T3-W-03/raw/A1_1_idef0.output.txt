## A0 context model

**A0 — Control timed tank filling**

The function fills the tank in timed phases, pauses between phases, and returns to the initial step when the target level is detected or stopping is required. The discharge valve remains closed.

### Signal vocabulary and interface mapping

The logical names below are used for receptivities and actuator outputs throughout the model.

| Logical arrow | Physical interface or source | Meaning |
|---|---|---|
| `start` | Rising-edge event derived from StartCommand, `%IX100.0` | TRUE only during the scan in which the button is pressed |
| `stop` | StopCommand, `%IX100.1` | Stop request |
| `LSH` | LSH, `%IX100.2` | Target-level indication at 2.4 m |
| `LSHH` | LSHH, `%IX100.3` | High-high-level indication at 2.7 m |
| `ton_q` | TON output Q | Filling-duration expiry indication |
| `tof_q` | TOF output Q | Filling activity and subsequent off-delay indication |
| `fill_valve` | FillValve, `%QX100.0` | Fill-valve command |
| `discharge_valve` | DischargeValve, `%QX100.1` | Discharge-valve command; always FALSE |

The interface mechanism supplies the one-scan `start` event; a maintained StartCommand is **not** a repeated start request.

## Controls defining the child functions

### A1 — Evaluate filling timers

- **Filling-step activity** is TRUE only while the filling step is active.
- **Timer-behavior rules:**
  - TON uses Filling-step activity as its IN condition and TON_Duration as its preset.
  - `ton_q` becomes TRUE after uninterrupted filling activity for TON_Duration.
  - Leaving the filling step resets TON.
  - TOF uses Filling-step activity as its IN condition and TOF_Duration as its preset.
  - `tof_q` is TRUE during filling and remains TRUE for TOF_Duration after filling activity becomes FALSE.
  - The pause ends when `tof_q` is FALSE—not merely when the filling step is left.

### A2 — Select the operating step

**Operating-step state** has three values:

| State | Meaning |
|---|---|
| Step 0 | Initial/idle step |
| Filling step | Active filling phase |
| Pause step | Timed interruption of filling |

The following rules are ordered by priority.

| Priority | Current state | Receptivity | Resulting state |
|---|---|---|---|
| 1 | Any state | `stop` | Step 0 |
| 2 | Any state | `LSHH` | Step 0 |
| 3 | Any state | `LSH` | Step 0 |
| 4 | Step 0 | `start AND NOT stop AND NOT LSH AND NOT LSHH` | Filling step |
| 5 | Filling step | `ton_q AND NOT LSH` | Pause step |
| 6 | Pause step | `NOT tof_q` | Filling step |
| 7 | Any state | No applicable receptivity | Unchanged state |

Additional controls:

- **Initialization rule:** Step 0 is active initially.
- **Stop-priority rule:** `stop` overrides every other receptivity.
- **Level-protection rules:** Level termination overrides timer-based transitions and a simultaneous `start`.
- **Sequence rules:** A new filling cycle requires a new `start` event. Returning to Step 0 does not create an automatic restart.
- Priority 5 and 6 apply only when higher-priority rules are inactive.

### A3 — Command the tank valves

| Operating condition | `fill_valve` | `discharge_valve` |
|---|---:|---:|
| Step 0 | FALSE | FALSE |
| Filling step, with `stop`, `LSH`, and `LSHH` all FALSE | TRUE | FALSE |
| Pause step | FALSE | FALSE |
| `stop` TRUE, regardless of state | FALSE | FALSE |
| `LSH` or `LSHH` TRUE, regardless of state | FALSE | FALSE |

This output gating prevents a stale filling-state indication from maintaining the fill command during a stop or level-termination scan.

## High-high-level constraint

“**LSHH must never be reached**” is a plant-level constraint, not something timer settings alone can guarantee. Normal termination occurs at `LSH` at 2.4 m. The 0.3 m margin to `LSHH` must accommodate level-switch response, communication and scan delays, valve closure time, and residual inflow.

The `LSHH` stop and output inhibition above are an explicit defensive addition. They close the valve if high-high level is detected, but **cannot prove that high-high level was never reached**. That guarantee requires validation of the plant dynamics and response-time margin.
