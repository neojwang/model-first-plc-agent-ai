## A0 context model

**A0 — Control the tank level**

**Scope:** Control the Factory I/O tank through OpenPLC and the Modbus TCP interface, from acquisition of commands and level feedback to generation of valve register commands.

**Boundary:** The tank and its hydraulic behavior are external to the controller. Level feedback enters the model; valve commands leave it.

In the tables below, function names are verb phrases. Arrow names are noun phrases; the required identifiers `start`, `stop`, `settled`, `r`, `fill_valve`, and `discharge_valve` are retained exactly.

### Context ICOM table

| Node | Function | Inputs | Controls | Outputs | Mechanisms |
|---|---|---|---|---|---|
| A0 | Control the tank level | StartCommand signal; StopCommand signal; LevelMeter register value | Initial-step requirement; start-event definition; stop-priority rule; regulation and termination rules; FULL_SCALE value; level measuring span; target level; overfill limit; tolerance band; hold duration; PID gains; output saturation rule; integration-suspension rule; discharge-opening requirement; I/O mapping specification | FillValve register command; DischargeValve register command | OpenPLC Runtime; PLC scan execution; Modbus TCP interface; Factory I/O analog driver |

## Arrow definitions and interfaces

### External arrows

| Arrow | Definition |
|---|---|
| StartCommand signal | BOOL at `%IX100.0`. |
| StopCommand signal | BOOL at `%IX100.1`. |
| LevelMeter register value | INT at `%IW100`, proportional to the level-meter voltage. |
| FillValve register command | INT written to `%QW100`, representing fill-valve opening. |
| DischargeValve register command | INT written to `%QW101`, representing discharge-valve opening. |
| FULL_SCALE value | `1000`, corresponding to 10 V with Factory I/O driver Scale = 100. |
| PID gains | Parameters `Kp`, `Ti`, and `Td`. |

### Internal arrows

| Arrow | Definition and connection |
|---|---|
| `start` | Rising-edge event from A1 to A3; TRUE only for the scan in which StartCommand becomes TRUE. |
| `stop` | StopCommand state from A1 to A3 and A5; TRUE for every scan in which StopCommand is TRUE. |
| Measured level | Scaled level from A1 to A2: \(h=(\text{LevelMeter}/\text{FULL_SCALE})h_{\text{span}}\). |
| Level error | Error from A2 to A4: \(e=h_{sp}-h\). |
| `r` | Level-region classification from A2 to A3: `LOW`, `MID`, or `HIGH`. |
| `settled` | Continuous in-band qualification from A2 to A3. |
| Operating-step status | Current step from A3: step 0 or the regulation step. |
| Regulation-active status | Regulation-step indication from A3 to A2 and A4. |
| `fill_valve` | Boolean enable from A3 to A5; TRUE while the PID drives the fill valve. |
| `discharge_valve` | Boolean enable from A3 to A5; TRUE while the discharge valve is held at 40%. |
| Bounded fill-opening demand | PID demand from A4 to A5, limited to the interval 0–100%. |

The feedback connection from A3 to A2 enables and resets qualification timing. It is an IDEF0 control dependency, not an additional process input.

## Functional rules

### A1 — Acquire commands and scale level feedback

- Generate `start` from the rising edge of StartCommand, rather than its maintained TRUE state.
- Preserve StopCommand as the level-sensitive `stop` signal.
- Scale LevelMeter consistently with `FULL_SCALE = 1000`.

Using voltage-equivalent level units:

| Quantity | Value |
|---|---:|
| Measuring span \(h_{\text{span}}\) | 10 V |
| Target \(h_{sp}=h_{\text{target}}\) | 8 V, equivalent to register value 800 |
| Overfill limit \(h_{\max}\) | 9 V, equivalent to register value 900 |
| Tolerance \(\varepsilon\) | 0.2 V, equivalent to 20 register counts |

### A2 — Evaluate level conditions and qualification time

Classify the level using exactly these regions:

- `r = LOW` when \(h<h_{\text{target}}\).
- `r = MID` when \(h_{\text{target}}\le h<h_{\max}\).
- `r = HIGH` when \(h\ge h_{\max}\).

Generate `settled` only after \(|e|\le\varepsilon\) has remained continuously TRUE for 10 s during regulation.

Reset qualification timing whenever:

- regulation is inactive; or
- \(|e|>\varepsilon\).

Thus, separate visits to the tolerance band do not accumulate toward the hold duration.

### A3 — Manage the operating step

The following are behavioral rules for the state manager, not additional IDEF0 functions.

| Current step | Receptivity | Resulting step | Output-enable condition |
|---|---|---|---|
| Any step | `stop` | Step 0 | `fill_valve = FALSE`; `discharge_valve = FALSE` |
| Step 0 | `start` AND NOT `stop` | Regulation step | Both enables TRUE while the regulation step remains active |
| Step 0 | NOT `start` AND NOT `stop` | Step 0 | Both enables FALSE |
| Regulation step | NOT `stop` AND (`settled` OR `r = HIGH`) | Step 0 | Both enables FALSE |
| Regulation step | NOT `stop` AND NOT `settled` AND `r ≠ HIGH` | Regulation step | Both enables TRUE |

**Priority and initialization:**

- Step 0 is the initial step.
- `stop` overrides every other receptivity.
- `start` has no restart or timer-reset effect while regulation is already active.
- A start event does not override the overfill termination condition.
- Step 0 has no active valve-driving action; A5 explicitly enforces zero register commands rather than leaving previous output values in place.

### A4 — Calculate the bounded PID demand

While regulation is active:

- Use \(e=h_{sp}-h\) as the PID error.
- Calculate the PID demand using `Kp`, `Ti`, `Td`, and the execution interval.
- Clamp the demand to 0–100% opening.
- Suspend integral accumulation while the output is clamped.

While regulation is inactive, the PID demand has no authority over the valves. The integral and derivative initialization policy on entry to regulation must be defined during detailed design; it is not specified by the task.

### A5 — Generate valve register commands

| Condition | FillValve register command | DischargeValve register command |
|---|---:|---:|
| `stop = TRUE` | 0 | 0 |
| `fill_valve = FALSE` and `discharge_valve = FALSE` | 0 | 0 |
| Regulation active | Bounded PID demand scaled to 0–1000 | 400 |

The fill command is converted to INT using a defined numeric-conversion policy and remains bounded to 0–1000. The discharge command of 400 represents 40% opening, or 4 V.

**Completion behavior:** On `settled`, `r = HIGH`, or `stop`, the controller returns to step 0 and commands both valves closed in the applicable control scan.
