The model below treats **A0 as the context function**, decomposed into **A1–A3**. Arrow names use the prescribed identifier vocabulary where applicable. **`timer_done` is an internal arrow**, generated by A2 rather than supplied by the plant.

| Node | Function | Inputs | Controls | Outputs | Mechanisms |
|---|---|---|---|---|---|
| **A0** | **Control timed tank filling** | `start`; `stop`; `LSHH`; `LSH` *(available but unused)* | `TimerDuration`; initial-step requirement; start-triggered filling rule; timer-or-high-high termination rule; stop-priority rule; discharge-closure requirement; I/O address mapping | `fill_valve`; `discharge_valve` | OpenPLC Runtime; Factory I/O tank scene and capacitive level switches; Modbus TCP connection; start-button event detection; PLC timer and state storage |
| **A1** | **Manage filling-cycle state** | `start`; `stop`; `LSHH`; `timer_done` | Initial-step requirement; start-triggered filling rule; timer-or-high-high termination rule; stop-priority rule | Filling-step state | OpenPLC cyclic execution; step-state storage |
| **A2** | **Measure filling-step duration** | Filling-step state | `TimerDuration`; timer-start requirement; timer-reset requirement | `timer_done` | OpenPLC timer instance; PLC time base |
| **A3** | **Set valve commands** | Filling-step state; `stop`; `LSHH`; `timer_done` | Initial-step output-inhibition requirement; filling-step output rule; stop-priority rule; discharge-closure requirement; output address mapping | `fill_valve`; `discharge_valve` | OpenPLC output logic and output image; Modbus TCP connection; Factory I/O valve interfaces |

### Interpretation of the function boundaries

- **A1 — Manage filling-cycle state:** Initialize to **step 0**. Accept `start` only from step 0 to enter the filling step. Return to step 0 on `stop`, `LSHH`, or `timer_done`. **`stop` takes precedence over `start`**; a termination condition must not permit a filling command.
- **A2 — Measure filling-step duration:** Start timing on entry to the filling step. Assert `timer_done` when `TimerDuration` has elapsed. Reset the timer when the filling step is inactive, so each new filling cycle receives a fresh timing interval.
- **A3 — Set valve commands:** Set `fill_valve` TRUE only while the filling step is active and no stop or termination condition applies. Keep `discharge_valve` FALSE at all times. Both outputs are FALSE in step 0.
- **`LSH` is not a transition condition.** The 2.4 m switch is available in the scene, but the stated task terminates filling only on timer completion or the 2.7 m `LSHH` condition.

The interface mapping is `start` ← rising-edge event of `StartCommand` at `%IX100.0`; `stop` ← `%IX100.1`; `LSH` ← `%IX100.2`; `LSHH` ← `%IX100.3`; `fill_valve` → `%QX100.0`; and `discharge_valve` → `%QX100.1`.
