Control task:
# Task T4 - Factory I/O Level Control, PID control

Plant: the tank of the Factory I/O "Level Control" scene in the analog configuration.

I/O (OpenPLC Runtime with Factory I/O attached as a Modbus TCP slave device; map the scene tags to these addresses in the Factory I/O driver):
- Inputs: StartCommand AT %IX100.0 : BOOL; StopCommand AT %IX100.1 : BOOL; LevelMeter AT %IW100 : INT (level meter, 0-10 V; the register value is proportional to the voltage).
- Outputs: FillValve AT %QW100 : INT (fill valve opening, 0-10 V); DischargeValve AT %QW101 : INT (discharge valve opening, 0-10 V).
- Constant: FULL_SCALE : INT := 1000 (the register value that corresponds to 10 V; the Factory I/O driver uses Scale = 100).
- Parameters: set point h_sp = h_target = 0.8 h_span; overfill limit h_max = 0.9 h_span; tolerance band eps = 0.02 h_span; hold time t_h = 10 s; PID gains Kp, Ti, Td; h_span is the measuring span of the level meter (10 V).

Requirements:
1. Step 0 is the initial step; it drives no output.
2. On StartCommand, regulate the level: drive the fill valve with the output of a PID controller (error e = h_sp - h), clamp the PID output to 0-100 % of the valve opening and suspend integration while the output is clamped, and hold the discharge valve at a constant opening of 40 % (4 V, that is, 0.4 FULL_SCALE).
3. End regulation when |e| <= eps has held for t_h, or when h >= h_max; then close both valves and return to step 0.
4. Whenever StopCommand is TRUE, return to step 0 with all outputs at 0.

Identifier vocabulary for receptivities and outputs (use exactly these names):
- inputs: start (the event of pressing StartCommand: TRUE only in the scan in which the button is pressed), stop, settled (|e| <= eps has held for t_h), r (level region: r = LOW for h < h_target, r = MID for h_target <= h < h_max, r = HIGH for h >= h_max)
- outputs: fill_valve (TRUE while the PID drives the fill valve), discharge_valve (TRUE while the discharge valve is held at 40 %)

## Behavioral controls attached to the model

### 1. Scaling and classification

A1 applies:

\[
h=\frac{\text{LevelMeter}}{\text{FULL\_SCALE}}h_{\text{span}},
\qquad e=h_{\text{sp}}-h
\]

With `FULL_SCALE = 1000`, the equivalent register-domain values are:

- Target level: **800**
- Overfill threshold: **900**
- Tolerance: **±20**

The required classification is:

- `r = LOW` when \(h < h_{\text{target}}\)
- `r = MID` when \(h_{\text{target}} \le h < h_{\max}\)
- `r = HIGH` when \(h \ge h_{\max}\)

### 2. Operating-step selection

A3 applies the following priorities:

1. **Stop priority:** whenever `stop` is TRUE, select step 0 and make both logical outputs FALSE.
2. **Regulation termination:** during step 1, `settled` or `r = HIGH` selects step 0.
3. **Start acceptance:** in step 0, `start` selects step 1 only when `stop` is FALSE and `r` is not `HIGH`.
4. Otherwise, retain the operating step.

The initial step is **step 0**.

| Operating step | `fill_valve` | `discharge_valve` |
|---|---:|---:|
| Step 0 — idle | FALSE | FALSE |
| Step 1 — regulation | TRUE | TRUE |

A start event at an already excessive level therefore produces no valve-opening command. A held start button cannot restart regulation after completion; a new `start` event is required.

### 3. Tolerance timing

A2 asserts `settled` only after:

\[
|e|\le eps
\]

has remained continuously true for **10 s during regulation**.

The timer resets whenever the level leaves the tolerance band or the operating step is step 0. Thus, idle time does not count toward completion of a later regulation cycle.

### 4. PID limiting

While `fill_valve` is TRUE, A4 calculates the PID demand from `e`, limits it to **0–100%**, and **suspends integral accumulation while the output is clamped**.

The final demand is evaluated with the current scan’s error before A5 issues the valve commands.

### 5. Valve-command enforcement

A5 enforces:

\[
\text{FillValve}=
\begin{cases}
\operatorname{INT}\!\left(\dfrac{\text{Limited PID demand}}{100}\,
\text{FULL\_SCALE}\right), & \text{if fill\_valve}\\
0, & \text{otherwise}
\end{cases}
\]

\[
\text{DischargeValve}=
\begin{cases}
0.4\,\text{FULL\_SCALE}=400, & \text{if discharge\_valve}\\
0, & \text{otherwise}
\end{cases}
\]

Step 0 has no active valve action; A5 explicitly writes both analog commands to zero rather than leaving previous commands latched. Stop and termination decisions must therefore take effect before the current scan’s output commands are committed.

2. A transition lists its upstream steps ("from"), its downstream steps ("to"), and its receptivity ("guard"). Guards use only the input identifiers of the task card, step names, the operators !
